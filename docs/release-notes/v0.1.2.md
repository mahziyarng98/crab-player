An icon fix. Playback, the interface and the packages are otherwise the same
as 0.1.1.

## Changes

- **Readable small icons.** The 16×16 and 24×24 px icons are now drawn for
  those sizes instead of being downscaled from the large logo, so the crab
  and its play button stay recognisable in menus, task switchers and other
  small slots. The 32–512 px icons are unchanged.

## Install

`SHA256SUMS` lists the checksums; binaries are x86_64. The commands are the
same as for 0.1.1 with the new version:

```sh
# AppImage (any x86_64 distribution, glibc 2.35+)
chmod +x Crab_Player-0.1.2-x86_64.AppImage
./Crab_Player-0.1.2-x86_64.AppImage movie.mkv

# Debian 12+, Ubuntu 24.04+ (needs libmpv2)
sudo apt install ./crab-player_0.1.2-1_amd64.deb

# Fedora, openSUSE Tumbleweed
sudo dnf install ./crab-player-0.1.2-1.fc45.x86_64.rpm
# or: sudo zypper install ./crab-player-0.1.2-1.fc45.x86_64.rpm

# Arch Linux
sudo pacman -U crab-player-0.1.2-1-x86_64.pkg.tar.zst

# Flatpak (Flathub submission pending review)
flatpak install --user ./Crab_Player-0.1.2-x86_64.flatpak
flatpak run io.github.mahziyarng98.crab-player

# Tarball
tar xf crab-player-0.1.2-linux-x86_64.tar.gz && cd crab-player-0.1.2-linux-x86_64
scripts/install.sh
```
