A packaging release for the first Flathub submission. Playback and the
interface are unchanged from 0.1.0.

## Changes

- **New application id**: `io.github.mahziyarng98.crab-player` replaces
  `io.github.mahziyarng98.CrabPlayer`. Flathub requires an id that resolves to
  the project's repository, and this repository is
  `github.com/mahziyarng98/crab-player`. The desktop file, the AppStream
  metadata, the icons, the Wayland app id, the X11 class and the Flatpak id
  all use the new name; the binary, the config folder and the data folder
  stay `crab-player`.
- **Save Image uses the desktop save dialog.** `Ctrl+Shift+S` captures the
  frame and lets you choose the folder and file name instead of always
  writing to `~/Pictures/crab-player/`. The frame is read back on the GPU, so
  the capture also works while VA-API hardware decoding is active, and the
  save dialog opens only after the image has been written. This removes the
  Flatpak's pictures permission, so the sandbox now writes an image only
  where the portal grants access.
- **Narrower Flatpak sandbox.** Read-only access to `~/Videos` (drag and
  drop passes plain paths), network for streams and "Open URL", Wayland with
  X11 fallback, DRI and PulseAudio. `~/Music`, `~/Downloads` and
  `~/Pictures` are no longer mounted.
- The Flatpak manifest builds the release tag offline from a committed
  `cargo-sources.json`, and the AppStream metadata has new screenshots and
  branding for software centres.

## Install

`SHA256SUMS` lists the checksums; binaries are x86_64. The commands are the
same as for 0.1.0 with the new version:

```sh
# AppImage (any x86_64 distribution, glibc 2.35+)
chmod +x Crab_Player-0.1.1-x86_64.AppImage
./Crab_Player-0.1.1-x86_64.AppImage movie.mkv

# Debian 12+, Ubuntu 24.04+ (needs libmpv2)
sudo apt install ./crab-player_0.1.1-1_amd64.deb

# Fedora, openSUSE Tumbleweed
sudo dnf install ./crab-player-0.1.1-1.fc45.x86_64.rpm
# or: sudo zypper install ./crab-player-0.1.1-1.fc45.x86_64.rpm

# Arch Linux
sudo pacman -U crab-player-0.1.1-1-x86_64.pkg.tar.zst

# Flatpak (Flathub submission pending review)
flatpak install --user ./Crab_Player-0.1.1-x86_64.flatpak
flatpak run io.github.mahziyarng98.crab-player

# Tarball
tar xf crab-player-0.1.1-linux-x86_64.tar.gz && cd crab-player-0.1.1-linux-x86_64
scripts/install.sh
```

If you installed the Flatpak 0.1.0 bundle, uninstall it before installing
0.1.1: the app id changed, so the two are separate applications.

```sh
flatpak uninstall --user io.github.mahziyarng98.CrabPlayer
flatpak install --user ./Crab_Player-0.1.1-x86_64.flatpak
```
