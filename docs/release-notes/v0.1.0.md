First release of Crab Player, a fast and native media player for Linux,
written in Rust (egui for the interface, libmpv for playback) with a classic
desktop layout: a caption strip with the logo and menu, the video, a seek bar
over the transport controls, and a docked playlist.

## Features

- Plays **everything the installed FFmpeg supports**: local files, folders
  (added recursively) and network streams (`http(s)`, `rtsp`, `rtmp`, `udp`,
  `srt`, …). See `docs/codec-support.md` in the repository for what was
  tested.
- Files open from the command line, the file manager ("Open with", `file://`
  URIs), File ▸ Open (a native portal dialog), drag and drop (including on
  native Wayland), Open URL and the playlist's Add button.
- Video rendered inside the window through mpv's render API: sharp at
  fractional scale factors, letterboxed, with rotation and aspect-ratio
  override.
- Hardware decoding: VA-API zero-copy on Wayland, with an HW/SW badge that
  shows the active decoder and switches it. Hardware failures retry in
  software automatically.
- Track selection for audio, video and subtitles; external subtitles; audio
  and subtitle delay; A-B repeat; repeat, shuffle, speed and go-to-time.
- Picture controls, screenshot saving, and a Media Info dialog (container,
  codecs, profile, pixel format, resolution, frame rate, bitrates, channels,
  sample rate, decoder in use).
- Playlist with drag and drop, natural sorting by name or folder, random
  order.
- Full screen with fading auto-hiding controls (F, double click or middle
  click), layout presets, always on top on X11.
- Clear, non-blocking error messages for files that cannot be opened or
  decoded.
- Layout and settings persist in a TOML file.

## Install

Every package below is attached to this release; `SHA256SUMS` lists the
checksums. Binaries are x86_64.

**AppImage** — one file, any x86_64 distribution with glibc 2.35 or newer
(Ubuntu 22.04+, Debian 12+, Fedora 36+, openSUSE Tumbleweed, RHEL 10, Arch).
Bundles libmpv and FFmpeg; uses the system's graphics and VA-API drivers.

```sh
chmod +x Crab_Player-0.1.0-x86_64.AppImage
./Crab_Player-0.1.0-x86_64.AppImage movie.mkv
```

Without FUSE, run it as `./Crab_Player-0.1.0-x86_64.AppImage
--appimage-extract-and-run`.

**Debian 12+, Ubuntu 24.04+** — native package, needs `libmpv2`:

```sh
sudo apt install ./crab-player_0.1.0-1_amd64.deb
```

**Fedora, openSUSE Tumbleweed** — native package:

```sh
sudo dnf install ./crab-player-0.1.0-1.fc45.x86_64.rpm       # Fedora
sudo zypper install ./crab-player-0.1.0-1.fc45.x86_64.rpm    # openSUSE
```

Fedora's own FFmpeg omits H.264 and HEVC; enable RPM Fusion and run
`sudo dnf swap ffmpeg-free ffmpeg --allowerasing` for all codecs (Packman
does the same on openSUSE).

**Arch Linux** — `crab-player-0.1.0-1-x86_64.pkg.tar.zst`, uses the system
mpv and FFmpeg:

```sh
sudo pacman -U crab-player-0.1.0-1-x86_64.pkg.tar.zst
```

**Flatpak** — bundles its own runtime and FFmpeg:

```sh
flatpak install --user ./Crab_Player-0.1.0-x86_64.flatpak
flatpak run io.github.mahziyarng98.crab-player
```

**Tarball** — prebuilt binary plus `install.sh`, for a distribution with its
own `libmpv.so.2`:

```sh
tar xf crab-player-0.1.0-linux-x86_64.tar.gz && cd crab-player-0.1.0-linux-x86_64
scripts/install.sh                             # into ~/.local, no root
sudo scripts/install.sh --prefix /usr/local    # or system-wide
```

## Known limitations

- Zero-copy hardware decoding works on Wayland only; on X11/Xwayland it is
  hardware decoding with a copy back, and on software OpenGL (llvmpipe) it
  decodes in software.
- NVIDIA NVDEC is left to mpv's defaults and has not been tested.
- Idle memory is about 170 MB, above the project's own 70 MB target.
- Always on top does nothing on native Wayland, which has no protocol for it.
- Track selection, delays and picture settings are not remembered per file.
- No subtitle styling, equalizer, shaders or thumbnail capture yet (the
  menu entries are shown disabled).
- In the Flatpak the clipboard is unavailable, so "Copy location" does
  nothing there.
- Packages were built and install-tested in containers and on one Arch
  Linux machine; see `docs/packaging.md` for exactly what was tested where.
