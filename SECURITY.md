# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue: use
GitHub's private vulnerability reporting on this repository
(**Security → Report a vulnerability**,
<https://github.com/mahziyarng98/crab-player/security/advisories/new>).

Include what is affected (version, install format), how to reproduce it,
and the impact you expect. You will get an answer through the advisory;
fixes are released as a new version and credited unless you prefer
otherwise.

## Scope

Crab Player hands media decoding to libmpv and FFmpeg. Problems in those
libraries should be reported to their projects; if Crab Player makes one
reachable in a way the libraries do not expect, report it here.

## Supported versions

Only the latest release receives fixes.
